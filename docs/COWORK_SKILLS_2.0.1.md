# Skills and Cowork

FeatherScript uses one task pipeline. It never selects a reasoning tier or changes the selected provider model/thinking control. Profiles select tool scope: RobloxScript focuses on Studio; AgentScript focuses on PC work under desktop permissions.

Relevant skill main instructions are ranked from the installed metadata. Up to two matching documents are prefetched within an 18,000-character budget. The complete active catalogue remains available through feather_getskills. Supporting references and scripts are listed but loaded only when needed, using skill plus file. Main-instruction cache entries are scoped to the provider and conversation and expire after two minutes. Backend metadata caching invalidates when the source file changes.

The VFX Mastery pack is the main effect-authoring guide. Older overlapping VFX guidance was absorbed into its main document and supporting references; original folders remain archived. Asset-harvesting tooling remains a separate skill. The active catalogue contains 54 skills, with no identical normalized main documents. Two empty templates are archived.

Cowork is opt-in. Add prompts, enable the queue, then Resume. Work runs one task at a time. Pause preserves the running task; Stop cancels it and pauses subsequent tasks. Reload never silently replays work: running jobs become interrupted. Old saved queue prompts survive the removal of per-task mode settings. Review uncertain outcomes before repeating a write.

Local task activity records durations, known skill loads and tool counts. They are not provider-internal reasoning telemetry or a quality score. Existing command IDs, acknowledgement/result separation, safe cancellation, permission enforcement and Auto Playtest remain independent of task context.

Restart the desktop app, reload the matching unpacked extension and refresh existing chat tabs after upgrading.

For automatic AgentScript context, mark a PC skill with `scope: pc` in its SKILL.md front matter, or use a `pc-` folder prefix. Roblox-only skill context is not automatically injected into PC tasks. Merged skill names resolve to their canonical folder without adding duplicate catalogue entries.
