# Studio write boundaries

Before an edit, identify its smallest target in Explorer. Before replacing a script, inspect how it is required, connected, or referenced. Before changing a shared remote or replicated object, inspect both server and client consumers.

Use a narrow edit and inspect the resulting instance immediately. Keep a copy of the previous script source or a clear undo point when the edit is substantial. Do not batch destructive operations into a Command Bar command. Ask for the user's intended behavior if a choice could discard data or change a live experience.

The final report must say whether the work was proposed, applied, or tested. Studio edit-mode screenshots do not prove runtime behavior.
